IMPULSWXE is an alternative analytical software for 
the data collection and analysis on Windows.

Download and unzip  IMPULSWXE.ZIP. 
Run exe-file: IMPULSWXE.EXE 
ListSample1.lst should be loaded.

How to manage thousands of recordings in a single file is here.

No tables, no pages, no million of numbers before your eyes.

Resulting statistical output with vector graphics.

Instant access to any numerical input or output arrays.

Comments applied for all categorized items.

Data transfer from/to MS Excel, ImageJ or AxioVision (Zeiss). 

ABF file processing.

It can be online notebook for experimental recordings.

See pptx-files from Help menu or use [F1]
