Impulswxe software for Windows

Software application is assigned for the numerical data 
management and analyzing  without spreadsheet interface.
It works with the local drives on Windows platforms.

It employs the multi-window interface with vector graphics.
Any plot window can be used for the data input and output.
The drawing plots can be copied to clipboard in metafile, jpeg or
or numerical formats.

The data list (or data base) window is the main module for data management. 
It can contain virtually unlimited number of file items associated with data arrays 

All list items have to be categorized by identification groups. 
Comments for any items are applicable and recommended. 

The user data are transferred to the data base by the file import, 
clipboard, manually, or internally processed resulting 
or acquisition file (ABF).

Download and unzip  IMPULSWXE.ZIP
Run IMPULSWXE.EXE 
ListSample1.lst should be loaded.

See pptx-files from Help menu or use [F1]
